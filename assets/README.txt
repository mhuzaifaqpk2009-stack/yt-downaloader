# Assets folder

Place an `app_icon.ico` file here (256x256 multi-resolution ICO recommended)
to embed a custom icon in the built .exe and installer.

If no icon is present, both builds will still work — they'll just use the
default PyInstaller icon.

You can create a simple icon with free tools like:
- https://icoconvert.com/  (convert a PNG to ICO)
- https://favicon.io/       (favicon/ICO generator)

A 256x256 image with 32-bit color depth is ideal for Windows.
