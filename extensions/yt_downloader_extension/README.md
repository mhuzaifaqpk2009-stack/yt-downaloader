Install the extension in Chrome/Edge (developer mode):

1. Open `chrome://extensions/` (or `edge://extensions/`).
2. Enable "Developer mode".
3. Click "Load unpacked" and select the `extensions/yt_downloader_extension` folder.
4. Right-click on a YouTube page and choose "Open with YT Downloader".

The extension sends the chosen URL to the native host over Chrome Native Messaging; the host forwards it to the running app or launches the app if needed.
